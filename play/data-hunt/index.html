Hunt the Data Treasure

How to play

  1. Read the clue — it describes the treasure by its properties.
  2. Rule out everything on the shelf that does not match.
  3. Use the next clue to narrow what is left.
  4. Pick the object the clues point at.

What it teaches

This is what a query really is: not code to be memorised, but a description precise enough that exactly one thing survives it. Where colour is blue and size is small is a filter, and stacking filters is how every database search in the world works. Meeting that idea as a treasure hunt means the eventual encounter with real SQL is a notation change rather than a new concept.
